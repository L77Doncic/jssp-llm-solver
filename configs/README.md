# configs/ — 实验配置目录

按阶段分三个子目录，每个配置使用 YAML 文件，一条实验 = 一份配置 + 一个实验目录（`experiments/<exp_name>/`）：

| 子目录 | 内容 |
|--------|------|
| `data/` | 实例生成与监督数据构建参数（规模、生成方式、求解器超时等） |
| `sft/` | 监督微调参数（模型、LoRA、数据比例、学习率、epoch 等） |
| `foarl/` | 强化学习阶段参数（奖励权重 λ、GRPO 组大小、KL 系数、BoN 采样等） |

## 约定
- 配置文件名即实验名（如 `data/jssp_10x10.yaml`），实验产物统一落在 `experiments/<实验名>/`。
- 所有随机种子必须在配置中显式声明，保证可复现。
- 修改配置请新增文件，不覆盖历史配置（实验结果需可追溯）。
